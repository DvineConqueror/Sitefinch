- Hide the local photo code by default on new copies saved to Gallery and in the quick-share preview after capture.
- Turn on **Include local code on Gallery copies** in Settings to show the code when the selected template includes it.
- Use **Show local photo code** in Photo details to reveal the code for that photo. The switch also controls whether an enabled code appears on the stamped copy you share.
- Reveal a clip’s ID only when you turn on **Show clip ID** in Clip details.
