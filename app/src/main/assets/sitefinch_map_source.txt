The GeoJSON geometry was simplified using Douglas–Peucker with a tolerance of 0.025 degrees, then rounded to 0.01 degrees. Consecutive duplicate points and shapes collapsed by simplification were omitted. The app uses only the geometry.

The binary starts with ASCII SFM1 and a big-endian unsigned 16-bit shape count. Each shape has a one-byte closed flag and a big-endian unsigned 16-bit path count. Each path has a big-endian unsigned 16-bit point count followed by big-endian signed 16-bit longitude and latitude pairs in hundredths of a degree. Land polygons store the outer path followed by any holes. Paths for polygons are implicitly closed.
