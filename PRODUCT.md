# Work Photo Log

A native Android camera and project album for field workers documenting jobs. The first release runs offline and preserves an original, unbranded JPEG for every saved capture. Workers can add a job note, record their location with permission, share a separately stamped copy, and export a project as an evidence ZIP.

Every capture uses device time. Location can be precise, approximate, or unavailable. The share flow makes location disclosure explicit. The local digest helps users check whether a saved photo still matches the recorded hash.
